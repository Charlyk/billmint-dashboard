    1. Create `src/lib/logging/route-handler.ts` — Route handler wrapper with automatic logging:
       - This wraps individual route handler functions (GET, POST, etc.) to automatically log:
         - Request: method, path, query params (sanitized)
         - Response: status code, response time in ms
         - Errors: full sanitized error context with stack trace
         - All logs include correlationId
       - Export type `RouteHandler = (request: NextRequest, context?: { params: Promise&lt;Record&lt;string, string&gt;&gt; }) => Promise&lt;Response&gt;`
       - Export `withLogging(handler: RouteHandler): RouteHandler` function:
         ```
         return async (request, context) => {
           const startTime = Date.now();
           const correlationId = getCorrelationId() || request.headers.get('x-correlation-id') || generateCorrelationId();
           const method = request.method;
           const path = new URL(request.url).pathname;

           try {
             const response = await handler(request, context);
             const duration = Date.now() - startTime;

             logger.info('API response', {
               service: 'api',
               correlationId,
               method,
               path,
               statusCode: response.status,
               duration,
             });

             // Set correlation ID on response if not already present
             if (!response.headers.has('x-correlation-id')) {
               // Response headers may be immutable — clone if needed
               // Actually, Response from route handlers is mutable before return
             }

             return response;
           } catch (error) {
             const duration = Date.now() - startTime;

             logger.error('API error', {
               service: 'api',
               correlationId,
               method,
               path,
               duration,
               error: sanitizeError(error),
             });

             // Re-throw to let the existing handleError pattern work
             throw error;
           }
         }
         ```
       - IMPORTANT: The wrapper should NOT call handleError itself. It logs and re-throws. The existing try/catch in route handlers calls handleError. This way the wrapper is additive, not replacing existing error handling.
       - Import `getCorrelationId, generateCorrelationId` from `./correlation`
       - Import `logger` from `./logger`
       - Import `sanitizeError` from `./sanitizers`
       - Import `NextRequest` from `next/server`
