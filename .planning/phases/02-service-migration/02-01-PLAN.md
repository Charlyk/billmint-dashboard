Replace all 16 console.error/console.log calls in invoice.service.ts with structured Axiom logging.

   ```typescript

   import { sanitizeError } from '@/lib/logging/sanitizers'
   ```

2. Create service logger after imports:
   ```typescript
   const log = createServiceLogger('invoice')
   ```

3. Replace each console.error with log.error, following this pattern:
   - Extract operation name from the existing log message (e.g., `[Invoice] create_invoice RPC error` becomes operation: 'create_invoice')
   - Use sanitizeError(error) for all error objects
   - Add relevant context (IDs, operation names) as structured fields
   - Use descriptive messages: "Failed to create invoice" not "RPC error"

   Example transformation:
   ```typescript
   // BEFORE:
   console.error('[Invoice] create_invoice RPC error:', error)
   // AFTER:
   log.error('Failed to create invoice', { operation: 'create_invoice', error: sanitizeError(error) })
   ```

4. Replace each console.log with appropriate level:
   - Informational messages (e.g., "Sending reminder email") -> log.info with context
   - Success confirmations -> log.info with context

5. Ensure NO console.error or console.log calls remain in the file.

Do NOT change any business logic, error handling flow, or throw statements. Only replace the logging calls.
